# UsageExtractor

**Description:** Parses llama-server JSON responses to extract token usage statistics (prompt/completion tokens, timing data). Used by `ResponseUsageMiddleware` for usage tracking.

## Data Model

### TokenUsage Record
```csharp
public sealed record TokenUsage(
    int PromptTokens,
    int CompletionTokens,
    int TotalTokens,
    double? PromptMs,
    double? CompletionMs,
    bool? CacheHits);
```

**Fields:**
- `PromptTokens`: Tokens in input prompt
- `CompletionTokens`: Tokens generated by model
- `TotalTokens`: Sum of prompt + completion tokens
- `PromptMs`: Time to process prompt (optional)
- `CompletionMs`: Time to generate completion (optional)
- `CacheHits`: Whether response served from KV cache (optional)

## Extraction Pattern

Parses llama-server JSON response structure:
```json
{
  "choices": [{
    "finish_reason": "stop",
    "text": "...",
    "usage": {
      "prompt_tokens": 150,
      "completion_tokens": 300,
      "total_tokens": 450,
      "timing": {
        "prompt_ms": 120.5,
        "completion_ms": 450.2,
        "cache_hits": true
      }
    }
  }],
  "usage": { ... },
  "model": "qwen36-smart"
}
```

**Extraction:**
- `usage` field may be at root level or nested in `choices[0].usage`
- `timing` object is optional (some llama-server versions omit it)
- All numeric fields are integers except timing (doubles)

## Streaming Detection

```csharp
public static bool IsStreaming(HttpContext context)
{
    var accept = context.Request.Headers["Accept"].ToString();
    return accept.Contains("text/event-stream") 
        || accept.Contains("application/stream+json");
}
```

**Behavior:**
- Returns `true` for SSE or streaming JSON responses
- Usage extraction skipped for streaming (stats unavailable until completion)
- Middleware passes through without buffering
