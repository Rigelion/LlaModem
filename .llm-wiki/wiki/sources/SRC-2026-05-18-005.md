# RequestForwarder

## Summary

Proxies HTTP requests from clients to llama-server backends. Handles header injection, backend URL selection, and error response formatting.

**Dependencies:**
- `IModelProxyHandler` — Prepares request (injects headers, selects backend)
- `ErrorResponseWriter` — Structured error responses
- `ILogger<RequestForwarder>` — Request/response logging_

## Key Takeaways

- **No streaming support** — Full response buffered for usage capture (streaming not supported)
- **5-minute timeout** via `IHttpClientFactory` for backend requests
- **Structured errors** via `ErrorResponseWriter.WriteAsync()` with consistent JSON format
