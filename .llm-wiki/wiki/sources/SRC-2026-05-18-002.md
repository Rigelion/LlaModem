# LlaModem — Root Architecture Overview

## Summary

LlaModem is a lightweight router for local LLM servers that exposes an OpenAI-compatible API. It routes requests to one of several `llama-server` backends based on the `X-Llama-Model` header, with automatic model lifecycle management (lazy start, idle shutdown, hot switching).

The project uses a layered architecture with dependency injection, configuration records bound via `IOptions<T>`, and Minimal API endpoints. Key components include `ModelManager` for lifecycle orchestration, `RequestForwarder` for HTTP proxy logic, and middleware for usage capture, authentication, and logging._

## Key Takeaways

- **Layered architecture**: Config → Services → Middleware → Endpoints with DI container setup in `Program.cs`
- **Minimal API pattern**: Extension methods like `MapStatsEndpoints()` organize endpoint registration
- **Model lifecycle**: Lazy start, hot switching, idle shutdown (600s default), health checks
- **Usage tracking**: SQLite persistence via Dapper with cost comparison against cloud models
- **Header injection**: HTTP headers mapped to JSON body fields with auto-type conversion
