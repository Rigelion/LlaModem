# LlaModem.Tests

## Summary

Unit test project using xUnit framework. Focuses on service logic, middleware behavior, and utility functions with in-memory mocks.

**Module Structure:**
- `DashboardEndpointTests.cs` — Admin endpoint handlers (status, stats)
- `ErrorResponseWriterTests.cs` — Structured error responses
- `HeaderValueInjectorTests.cs` — HTTP header to JSON body mapping
- `HttpConstantsTests.cs` — Route prefixes, header names
- `HybridRoutingTests.cs` — Model routing logic
- `ModelLifecycleTests.cs` — Lifecycle management (start, stop, switch)
- `RequestForwarderTests.cs` — Proxy behavior and error handling
- `ResponseUsageMiddlewareTests.cs` — Usage capture logic
- `StatsServiceTests.cs` — Cost comparison and aggregation_

## Key Takeaways

- **In-memory mocks** — `InMemoryModelRepository`, fake HTTP clients for isolation
- **Focus areas** — Service logic, middleware behavior, utility functions (not endpoint routing)
- **xUnit framework** — Standard .NET testing with async/await patterns
