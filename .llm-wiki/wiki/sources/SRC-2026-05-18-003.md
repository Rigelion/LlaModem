# DashboardService

## Summary

Admin endpoint handlers for model control, status queries, and usage statistics. All endpoints are unauthenticated (open to local network).

**Dependencies:**
- `IMetaModelManager` — Model lifecycle operations (switch, stop, get active)
- `IStatsService` — Usage aggregation and cost comparison
- `IUsageService` — Recent request retrieval
- `ILogger<DashboardService>` — Structured logging_

## Key Takeaways

- **All endpoints unauthenticated** — accessible to anyone on local network (intended for trusted environments)
- **Minimal API pattern** — Endpoints registered via `app.MapStatsEndpoints()` extension method
- **Cost comparison** — Estimates cloud model costs for same token usage using `ModelPricing` table
