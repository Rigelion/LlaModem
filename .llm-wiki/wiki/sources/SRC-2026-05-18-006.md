# RequestLoggingMiddleware

Logs request details at debug level for debugging and auditing. Part of the middleware pipeline before authentication and proxying.

## Dependencies

| Dependency | Purpose |
|------------|---------|
| `ILogger<RequestLoggingMiddleware>` | Structured logging (debug level) |
| `IOptions<RouterConfig>` | Header injection config for body inspection |

## Middleware Pipeline Position

```
1. ResponseUsageMiddleware (capture usage stats)
2. RequestLoggingMiddleware ← here (log request details)
3. BasicAuthMiddleware (validate /v1/* routes)
4. Endpoint handlers
```

**Note:** Applied only to `/v1/*` routes via `app.UseRequestLoggingWhen("/v1")`.

## Logged Fields

| Field | Description | Example |
|-------|-------------|---------|
| `Method` | HTTP method | `POST` |
| `Path` | Request path | `/v1/chat/completions` |
| `ClientIp` | Client IP address | `192.168.1.100` |
| `Model` | Target model (from header) | `qwen36-smart` |
| `Headers` | Request headers (filtered) | `{ "X-Llama-Model": "..." }` |
| `Body` | Request body (JSON formatted) | `{ "model": "...", "messages": [...] }` |

## Logging Pattern

```csharp
public async Task InvokeAsync(HttpContext context)
{
    var path = context.Request.Path.Value ?? string.Empty;
    
    // Only log /v1/* routes
    if (!path.StartsWith("/v1", StringComparison.OrdinalIgnoreCase))
    {
        await _next(context);
        return;
    }

    // Capture headers
    var headers = new Dictionary<string, string>();
    foreach (var header in context.Request.Headers)
    {
        if (!IsHopByHopHeader(header.Key))
            headers[header.Key] = string.Join(", ", header.Value);
    }

    // Read body (if present)
    string? body = null;
    if (context.Request.ContentLength > 0)
    {
        context.Request.EnableBuffering();
        using var reader = new StreamReader(context.Request.Body, Encoding.UTF8);
        body = await reader.ReadToEndAsync();
        context.Request.Body.Position = 0; // Reset for downstream middleware
    }

    // Log at debug level
    _logger.LogDebug(
        "[REQUEST] {Method} {Path} — Client: {ClientIp}, Model: {Model}, Headers: {Headers}, Body: {Body}",
        context.Request.Method,
        path,
        context.Connection.RemoteIpAddress?.ToString(),
        headers.GetValueOrDefault("X-Llama-Model"),
        JsonSerializer.Serialize(headers),
        body ?? "no body");

    await _next(context); // Continue pipeline
}
```

## Header Filtering

**Skipped headers:** `Connection`, `Keep-Alive`, `Proxy-Authenticate`, `Proxy-Authorization`, `TE`, `Transfer-Encoding`, `Upgrade`

**Preserved headers:** All others including:
- `X-Llama-*` custom headers (model, temperature, top_p, etc.)
- `Authorization` — Basic auth credentials (masked in logs)
- `Content-Type`, `Accept` — Content negotiation headers

## Body Buffering

**Enable buffering:** `context.Request.EnableBuffering()` called before reading body

**Reset position:** `context.Request.Body.Position = 0` after reading to allow downstream middleware (e.g., [[entities/ResponseUsageMiddleware]]) to read body

**Conditional:** Only buffer if `ContentLength > 0` (POST/PUT requests)

## Debug Level Only

**Purpose:** Avoid logging sensitive data in production logs.

**Production config:** Set Serilog minimum level to `Information` or higher to suppress debug logs.

**Development config:** Set minimum level to `Debug` for full request/response visibility.

## Testing Patterns

**RequestLoggingMiddlewareTests.cs:**
```csharp
[Fact]
public async Task InvokeAsync_WhenV1Route_LogsRequestDetails()
{
    // Arrange
    var logger = new TestLogger();
    var middleware = new RequestLoggingMiddleware(logger, null);
    
    var context = new DefaultHttpContext
    {
        Request =
        {
            Method = "POST",
            Path = "/v1/chat/completions",
            Headers = { ["X-Llama-Model"] = "qwen36-smart" },
            Body = new MemoryStream(Encoding.UTF8.GetBytes("{\"model\":\"test\"}"))
        }
    };

    // Act
    await middleware.InvokeAsync(context);

    // Assert
    var logEntry = logger.DebugLogs.Single();
    Assert.Contains("[REQUEST]", logEntry);
    Assert.Contains("qwen36-smart", logEntry);
}
```

See `.rpiv/guidance/LlaModem.Tests/RequestLoggingMiddlewareTests.cs`.

## Performance Notes

- **Minimal overhead:** Debug-level logging only (skipped in production)
- **Buffering cost:** Body read into memory once, then reset position
- **JSON serialization:** Headers serialized for structured logging

## Security Notes

- **Debug level only:** Sensitive headers (Authorization) not logged at info/warn/error levels
- **Body content:** Full request body logged — may contain PII or secrets
- **Client IP:** Logged in plain text — consider anonymization in production
