# Configuration Layer

## Summary

Immutable configuration records bound from `appsettings.json` using the Options pattern (`IOptions<T>`). All config types are POCO records with no behavior.

**Module Structure:**
- `AppConfig.cs` — Root config, aggregates all sections
- `RouterConfig.cs` — Router settings (URL, auth, timeouts, header injection)
- `ModelConfig.cs` — Per-model configuration (start script, backend URL)
- `UsageConfig.cs` — Usage tracking settings (enabled flag, database path)
- `ProxyHeaders.cs` — Header mapping config for body injection_

## Key Takeaways

- **IOptions<T> pattern** — Configuration bound via `IOptions<T>` with `ValidateOnStart()`
- **Environment variable expansion** — `%VAR%` syntax expanded at startup, not per-request
- **Fail-fast validation** — Missing required fields throw during DI container build
