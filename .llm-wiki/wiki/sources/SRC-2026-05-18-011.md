# UsageExtractor (IUsageExtractor)

Parses llama-server JSON responses to extract token usage statistics (prompt/completion tokens, timing data). Used by [[entities/ResponseUsageMiddleware]] for usage tracking.

## Dependencies

None — pure parsing function with no external dependencies.

## Data Model

### TokenUsage Record

```csharp
public sealed record TokenUsage(
    int PromptTokens,
    int CompletionTokens,
    int TotalTokens,
    double? PromptMs,
    double? CompletionMs,
    bool? CacheHits);
```

**Fields:**
- `PromptTokens`: Tokens in input prompt
- `CompletionTokens`: Tokens generated by model
- `TotalTokens`: Sum of prompt + completion tokens
- `PromptMs`: Time to process prompt (optional)
- `CompletionMs`: Time to generate completion (optional)
- `CacheHits`: Whether response served from KV cache (optional)

### SessionEntry Record

```csharp
public record SessionEntry(
    DateTimeOffset Timestamp,
    string Model,
    string Route,
    TokenUsage Usage,
    DateTimeOffset RequestTime,
    DateTimeOffset ResponseTime,
    string? ClientIp,
    int StatusCode,
    IReadOnlyDictionary<string, string> RequestHeaders);
```

**Usage:** Created by [[entities/ResponseUsageMiddleware]] after extraction.

## Extraction Pattern

```csharp
public static class UsageExtractor
{
    public static TokenUsage? Extract(string json)
    {
        try
        {
            using var doc = JsonDocument.Parse(json);
            var root = doc.RootElement;
            
            // Get usage object (may be at root or nested in choices[0])
            var usageElement = root.TryGetProperty("usage", out _) 
                ? root.GetProperty("usage")
                : root.EnumerateArray().FirstOrDefault()
                    .GetProperty("choices").EnumerateArray().FirstOrDefault()
                    .GetProperty("usage");
            
            if (!usageElement.TryGetProperty("prompt_tokens", out var promptTokens))
                return null;
            
            var completionTokens = usageElement.GetProperty("completion_tokens").GetInt32();
            var totalTokens = usageElement.GetProperty("total_tokens").GetInt32();
            
            // Extract timing (optional)
            double? promptMs = null;
            double? completionMs = null;
            bool? cacheHits = null;
            
            if (usageElement.TryGetProperty("timing", out var timing))
            {
                if (timing.TryGetProperty("prompt_ms", out var p))
                    promptMs = p.GetDouble();
                
                if (timing.TryGetProperty("completion_ms", out var c))
                    completionMs = c.GetDouble();
                
                if (timing.TryGetProperty("cache_hits", out var h))
                    cacheHits = h.GetBoolean();
            }
            
            return new TokenUsage(
                PromptTokens: promptTokens.GetInt32(),
                CompletionTokens: completionTokens,
                TotalTokens: totalTokens,
                PromptMs: promptMs,
                CompletionMs: completionMs,
                CacheHits: cacheHits);
        }
        catch
        {
            return null; // Invalid JSON or missing usage field
        }
    }
    
    public static string? ExtractModel(string json)
    {
        try
        {
            using var doc = JsonDocument.Parse(json);
            return doc.RootElement.TryGetProperty("model", out var m) 
                ? m.GetString() 
                : null;
        }
        catch
        {
            return null;
        }
    }
    
    public static IReadOnlyDictionary<string, string> CollectLlamaHeaders(HttpRequestHeaders headers)
    {
        var result = new Dictionary<string, string>();
        
        foreach (var header in headers)
        {
            if (header.Key.StartsWith("X-Llama-", StringComparison.OrdinalIgnoreCase))
            {
                result[header.Key] = string.Join(", ", header.Value);
            }
        }
        
        return result;
    }
}
```

## JSON Response Format

**llama-server response structure:**
```json
{
  "choices": [
    {
      "finish_reason": "stop",
      "text": "...",
      "usage": {
        "prompt_tokens": 150,
        "completion_tokens": 300,
        "total_tokens": 450,
        "timing": {
          "prompt_ms": 120.5,
          "completion_ms": 450.2,
          "cache_hits": true
        }
      }
    }
  ],
  "usage": {
    "prompt_tokens": 150,
    "completion_tokens": 300,
    "total_tokens": 450,
    "timing": {
      "prompt_ms": 120.5,
      "completion_ms": 450.2,
      "cache_hits": true
    }
  },
  "model": "qwen36-smart"
}
```

**Notes:**
- `usage` field may be at root level or nested in `choices[0].usage`
- `timing` object is optional (some llama-server versions omit it)
- All numeric fields are integers except timing (doubles)

## Streaming Detection

```csharp
public static bool IsStreaming(HttpContext context)
{
    var accept = context.Request.Headers["Accept"].ToString();
    return accept.Contains("text/event-stream") 
        || accept.Contains("application/stream+json");
}
```

**Behavior:**
- Returns `true` for SSE or streaming JSON responses
- Usage extraction skipped for streaming (stats unavailable until completion)
- Middleware passes through without buffering

## Header Collection

**Llama-specific headers:** Headers starting with `X-Llama-` prefix:
- `X-Llama-Model` — Target model name
- `X-Llama-Temperature` — Sampling temperature
- `X-Llama-TopP` — Nucleus sampling threshold
- `X-Llama-MinP` — Min-p probability
- `X-Llama-TopK` — Top-K sampling limit
- `X-Llama-PresencePenalty` — Presence penalty
- `X-Llama-RepetitionPenalty` — Repetition penalty

**Usage:** Stored in `SessionEntry.RequestHeaders` for debugging.

## Error Handling

| Scenario | Behavior |
|----------|----------|
| Invalid JSON | Returns `null` (logged by middleware) |
| Missing usage field | Returns `null` |
| Malformed timing data | Skips timing fields (nullable) |
| Empty response body | Returns `null` |

## Testing Patterns

**UsageExtractorTests.cs:**
```csharp
[Fact]
public void Extract_WhenValidJson_ReturnsTokenUsage()
{
    // Arrange
    var json = @"{
      ""usage"": {
        ""prompt_tokens"": 150,
        ""completion_tokens"": 300,
        ""total_tokens"": 450,
        ""timing"": {
          ""prompt_ms"": 120.5,
          ""completion_ms"": 450.2,
          ""cache_hits"": true
        }
      }
    }";
    
    // Act
    var usage = UsageExtractor.Extract(json);
    
    // Assert
    Assert.NotNull(usage);
    Assert.Equal(150, usage!.PromptTokens);
    Assert.Equal(300, usage.CompletionTokens);
    Assert.Equal(450, usage.TotalTokens);
    Assert.Equal(120.5, usage.PromptMs);
}

[Theory]
[InlineData("{""usage"":{}}")] // Missing fields
[InlineData("not json")]       // Invalid JSON
[InlineData("")]               // Empty string
public void Extract_WhenInvalidJson_ReturnsNull(string json)
{
    var usage = UsageExtractor.Extract(json);
    Assert.Null(usage);
}
```

## Workflow: Usage Capture Flow

```
Non-streaming response received
  → ResponseUsageMiddleware.IsStreaming() returns false
  → UsageExtractor.Extract(rawJson) called
  → TokenUsage returned (or null if invalid)
  → SessionEntry created with timing data
  → UsageService.Record(entry) persists to SQLite
```

## Performance Considerations

- **Single JSON parse:** `JsonDocument` used (read-only, efficient)
- **No allocation:** Reuses existing buffers where possible
- **Null-safe:** Returns `null` on parsing errors (no exceptions thrown)
- **Timing optional:** Gracefully handles missing timing data

## Critical Notes

- **Non-streaming only:** Streaming responses bypass extraction (stats unavailable)
- **Optional timing:** Some llama-server versions omit `timing` object
- **Root or nested:** Handles both root-level and choices-nested usage fields
- **Model extraction:** Falls back to `(unknown)` if model field missing
