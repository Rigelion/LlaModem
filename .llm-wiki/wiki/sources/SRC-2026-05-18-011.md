# UsageExtractor

## Summary

Parses llama-server JSON responses to extract token usage statistics (prompt/completion tokens, timing data). Used by `ResponseUsageMiddleware` for usage tracking.

**Dependencies:** None — pure parsing function with no external dependencies._

## Key Takeaways

- **Non-streaming only** — Streaming responses bypass extraction (stats unavailable)
- **Optional timing** — Some llama-server versions omit `timing` object
- **Null-safe** — Returns `null` on parsing errors (no exceptions thrown)
